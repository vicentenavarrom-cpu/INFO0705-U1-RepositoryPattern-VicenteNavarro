# VetCare
Una aplicación de Android desarrollada en Kotlin para una clínica veterinaria.

## Descripción
El proyecto académico implementa:
- MVVM
- Clean Architecture
- Modularización
- Repository Pattern

## Módulos
- `:app`: Interfaz y ViewModel.
- `:domain`: Entidades e interfaz del Repository.
- `:data`: Implementación del Repository y fuentes de datos.

## Tecnologías
- Kotlin
- Android Studio
- Jetpack Compose
- Kotlin Coroutines
- StateFlow

## Funcionalidad
La aplicación muestra información de las mascotas obtenidas desde una fuente local y una fuente remota simulada.
